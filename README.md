# ColorCorrect

제시된 색을 색상 팔레트에서 직접 골라 얼마나 정확하게 맞히는지 겨루는 웹 게임입니다.

## 실행

빌드할 필요가 없어요. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 규칙

- 총 **5라운드**. 라운드마다 목표 색이 나와요.
- 라운드마다 **1번**만 제출할 수 있어요. 제출하면 정확도(%)가 나오고, 그 값이 바로 라운드 점수로 확정돼요.
- 제출 횟수는 `game.js`의 `MAX_TRIES`로 바꿀 수 있어요. 2 이상으로 올리면 시도마다 힌트(색조 방향 / 밝기 / 채도)가 나오고, 가장 높은 정확도가 라운드 점수가 돼요. "이 점수로 확정" 버튼으로 남은 시도 없이 일찍 끝낼 수도 있어요.
- 5라운드 평균 정확도로 등급을 매겨요.

| 등급 | 평균 정확도 |
| --- | --- |
| S | 95% 이상 |
| A | 90% 이상 |
| B | 80% 이상 |
| C | 70% 이상 |
| D | 60% 이상 |
| F | 60% 미만 |

### 모드

- **보면서 맞추기**: 목표 색이 계속 보여요.
- **기억해서 맞추기**: 목표 색이 3초 동안만 보이고 가려져요.

모드별 최고 기록은 브라우저(localStorage)에 저장돼요.

## 정확도 계산

두 색을 CIE L\*a\*b\* 색공간으로 바꾼 뒤, 사람 눈이 느끼는 색 차이에 가까운 **CIEDE2000(ΔE)** 으로 차이를 구해요.

```
정확도 = max(0, 100 − ΔE × 2.5)
```

ΔE가 0이면 100%, ΔE가 2 정도(거의 구분이 안 되는 차이)면 95%, ΔE가 40 이상이면 0%예요.

## 파일 구성

- `index.html`: 화면 구조 (시작 / 게임 / 결과)
- `style.css`: 스타일 (화이트 중심 무채색, 휴대폰 · 태블릿 · 데스크톱 반응형)
- `color.js`: HSV·RGB·Lab 변환과 CIEDE2000 계산
- `game.js`: 색상 팔레트(채도·밝기 사각형 + 색조 슬라이더)와 게임 진행
